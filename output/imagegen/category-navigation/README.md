# Category navigation imagery

Generated with the built-in imagegen tool on 2026-10-16, one image per category.
The artwork illustrates categories; product cards keep their individual photos.

Production files in `public/images/categories/`:

- `all-pieces-v1.webp` — varied tops, skirt and trousers.
- `dresses-v1.webp` — a complete sage shirt dress.
- `tops-blouses-v1.webp` — an ivory collared blouse.
- `skirts-pants-v1.webp` — an ivory skirt and olive trousers.
- `two-piece-sets-v1.webp` — a matching olive top and maxi skirt.

Full PNG originals are stored in this folder. The exact prompts are in
`prompts.json`. All prompts use consistent warm ivory studio surfaces, soft
daylight, clearly recognizable garment silhouettes, and no people or text.
