Sri Lanka COD is independent of the PayHere card gateway. The catalogue remains in AUD; Sri Lanka checkout shows and stores LKR totals.

Current launch setting is **demo mode**: illustrative catalogue AUD × 200, delivery LKR 400. These are mock prices, not an exchange-rate feed. Customers see a prominent test notice on delivery, payment, review and confirmation. Orders have a TEST prefix and an immutable server-side test flag. No funds are collected, stock reserved or customer records created for tests. Admin cannot dispatch, mark paid or print a packing slip for a test. Cancelling a test does not add stock.

Admin → Settings → Sri Lanka cash on delivery controls enable/pause, test mode, demo multiplier and LKR shipping. The main Accept new orders setting also applies. Admin → Products → Edit has an explicit LKR selling price for real COD. Real orders reject missing LKR prices; there is no automatic live conversion. Before turning off test mode, enter approved prices and delivery fees, confirm delivery operations, and review the published shipping/returns/terms for Sri Lanka. PayHere stays disabled until merchant approval and server credentials are configured.

Server quote and placement validate Sri Lanka address, district, 5-digit postal code, mobile number, product, size, quantity and stock. Client prices are ignored. A changed quote must be reviewed again. A request fingerprint and durable compare-and-swap protect retries and concurrent checkout. Confirmation is shown only after the order is saved. A successful COD checkout clears only purchased cart quantities, or only the isolated Buy Now item. No order-confirmation email service is currently configured; the on-screen confirmation is the receipt.

Real COD starts unpaid and can be packed/shipped before collection. Delivery completion requires recording collection as paid. Cancel unshipped real orders to release stock once. COD orders never expire through the PayHere reservation job. Admin formats order lines and totals in the order currency; TEST orders are excluded from sales and fulfilment statistics, and AUD/LKR revenue totals are separate.

Checks: `node scripts/check-cod.cjs`, `node scripts/check-security.cjs`, TypeScript/build, and browser delivery → COD → review → confirmation. Use QA/test-only contact details in demo mode. Do not dispatch or collect payment for TEST orders.
