# Rose Dot button retouch

Created with the built-in imagegen tool on 2026-10-16 at the client's request.
Original photographs in `Bindi/` are unchanged.

- `rose-dot-button-closeup.png`: edit of `Bindi/20261005_150735.jpg`.
- `rose-dot-button-waterfront.png`: edit of `Bindi/20261005_150612.jpg`.

Prompt intent for both edits: neatly fasten and align the existing topmost button,
close the small open notch at the top of the central placket, and smooth its
outward folded tab. Preserve the person, pose, garment design, existing buttons,
pink dots, texture, skirt, scenery, lighting and framing. No straps, sleeves,
neckline redesign, text or watermark. The closeup and landscape were edited
independently to match their original framing.

The final WebP assets and zoom versions are produced by
`python scripts/prepare_bindi_photos.py` and mapped in
`data/real-product-photos.json`. No API call is made by that preparation script.
